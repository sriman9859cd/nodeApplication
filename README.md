# nodeApplication

# Backend Setup

This project is built using Node.js and Express.js.

## Environment Details
-Node Version: v24.13.0
-NPM Version: 11.6.2

NPM is used in this project for package management.

## Project Setup
### Clone the Repository
```bash
-git clone repository-url
-cd nodeApplication
```
### Install Dependencies
```bash
npm install
```
## Run the Project
### Development Mode
```bash
npm run dev
```
### Production Mode
```bash
npm start
```

## nodemon
- Usage of nodemon is to run the code automatically without start everytime manually.
- It is a development tool.Hence it is devDependency.
## express
- Expresss is a runtime tool (dependency).
- It is used to create APIs, handle routes, and manage server-side logic.
## dotenv
- To keep sensitive data and configs separate from code.

## Db connection
- mysql2
- Sequelize(ORM)

### To Install sequelize CLI
```bash
npm install --save-dev sequelize-cli
```
### Initialize Sequelize
```bash
npx sequelize-cli init
```
This is automatically creates

```
config/
models/
migrations/
seeders/
```
### models/index.js

- It is auto-generated by Sequelize CLI.
- Its job is
-read DB config
-create DB connection
-load models

## MYSQL DB 
```bash
mysql -u root -p
```

## Migration
```bash
npx sequelize-cli db:migrate

1)migration:generate ---> Creates migration file
2)db:migrate ---> Executes migration
3)db:migrate:undo	---> Reverts last migration
```
A migration is like a version-controlled database change.
It helps you:
- create tables
- modify columns
- delete tables
- keep database structure organized
